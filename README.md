Library Management System

Project Description

The Library Management System is a console-based Java application developed using Object-Oriented Programming (OOP). It helps manage books, track book availability, and perform basic library operations.

Features

- Add new books to the library
- Display all books
- Issue books to users
- Return issued books
- Display user details
- Check book availability
- Prevent issuing a book that is already issued

Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- VS Code

OOP Concepts Used

- Encapsulation
- Classes and Objects
- Constructors
- HAS-A relationship

Project Structure

- "Book.java" – Stores book details and availability status.
- "User.java" – Stores user details.
- "Library.java" – Manages books, issuing, and returning operations.
- "Main.java" – Provides the menu-driven interface.
- ".gitignore" – Excludes compiled Java class files from Git.

How to Run the Project

1. Clone or download this repository.
2. Open the project in VS Code or Eclipse.
3. Ensure Java is installed on your system.
4. Run "Main.java".
5. Select the required options from the console menu.

How It Works

Users can add books by entering the book ID, title, and author name. They can display the book list, issue available books, and return issued books through the menu.

Data Storage

Book information is stored in an ArrayList during program execution. The data is not permanently stored and resets when the application stops.

Future Enhancements

- Integrate a MySQL database using JDBC.
- Store book information permanently.
- Support multiple users.
- Add book search functionality.
